- New package `@repo/factory-server-v2` at `apps/factory-server`; `apps/server` already owns `@repo/factory-server`, and a duplicate workspace name breaks `pnpm install`, so the legacy package stays untouched.
- Drizzle schema in `src/db/schema/`: 9 tables from PLAN §7 (`projects`, `safe_tokens`, `cells`, `order_plans`, `work_orders`, `order_steps`, `jobs`, `incidents`, `state_transitions`), column-for-column, FKs per the ER diagram.
  - The todo says 8 tables but lists 9 names; all 9 are created.
- Partial unique indexes via Drizzle `.where()`: `idx_jobs_one_active_per_order`, `idx_jobs_one_active_per_cell`, `idx_work_orders_one_active_per_cell`. Unique `state_transitions.command_id` and `work_orders.active_job_id`.
- `src/db/migrations/0000_init.sql` is generated by drizzle-kit from the schema, not hand-written; `db:check` runs `drizzle-kit check`.
- `createDb(path)` sets WAL, `synchronous = NORMAL`, `foreign_keys = ON`, `busy_timeout = 5000`, then runs the Drizzle migrator. `immediateTx` wraps `BEGIN IMMEDIATE`.
- Application core: `BaseError` subclasses 400-500 with `StaleLeaseEpoch` as 409 `stale-lease-epoch`.
  - `withZodSchema`: bad input gives 400 `Invalid request payload: <path>: <msg>`; undeclared or mismatched output gives 500.
  - Builders: `publicProcedure`, `scopedProcedure(scopes)`, `authenticatedProcedure`.
- Ports: `AuthPort` (`Principal`, `TokenScope`), `ClockPort`, `ClaimWaitersPort`, `TransitionBusPort`. Memory adapters for clock, claim waiters (cap 5) and transition bus.
- Hono: `honoAdapter`, `errorHandler`, `notFoundHandler`, and middlewares `requestId`, `noCache`, `payloadLimit`, `transportMiddleware`. `createTransport(deps)` builds per-request context; `createApp(createTransport)` wires it.
- `TransportDeps` also takes `auth`, not in the todo list, so authenticated procedures can verify tokens.
- No `src/index.ts` and no domain slices; `Bun.serve` lands in slice 06.
- Tests: 6 domain unit, 8 schema-index and 2 `immediateTx` DB tests (contention test waits the 5 s busy timeout), 10 black-box `app.request()` tests. 26 pass.
- Package gates pass through turbo: format, lint (`--max-warnings 0`), check-types, db:check, test.
