# `@repo/typescript-config`

Shared TypeScript configurations for the repository.

## Configurations

- `@repo/typescript-config/base.json`: Base TypeScript configuration with strict mode and NodeNext module resolution.
- `@repo/typescript-config/astro.json`: Configuration tailored for Astro applications with React JSX support and Bundler module resolution.
- `@repo/typescript-config/hono.json`: Configuration for Hono and Cloudflare Worker applications.
- `@repo/typescript-config/react-library.json`: Configuration for shared React packages and libraries.
