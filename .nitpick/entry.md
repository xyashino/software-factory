# Software Factory Agent Instructions

This repo is a bun + turbo monorepo. Apps live in `apps/`, shared packages in `packages/`, and the rule generator in `packages/nitpick`.

## Shared standards

- This file, the rules, skills and references listed below are the standards every role and interactive session follows.
- Proof of work follows {{ref:evidence}}.
- Every completed change adds exactly one ADR entry in `decisions/` ({{ref:decision-log}}).

## Where things live

- `.nitpick/`: source of truth for rules, skills, MCP settings and these docs. Edit here.
- `.agents/`, `AGENTS.md`, `CLAUDE.md`, `.mcp.json`: generated by `bun run nitpick:sync`. Never edit them by hand.
- `decisions/`: one entry per change. `todos/`: task specs. `docs/`: project docs.

## Commands

- `bun install`: installs, sets up husky and regenerates the AI docs.
- `bun run test`, `bun run lint`, `bun run check-types`, `bun run format:check`: run for every package a change touches.
- `bun run nitpick:sync`: regenerate after editing `.nitpick/`.
- `bun run nitpick:check`: fail if generated files or the rules are out of sync.

## Working on a change

1. Read the rule groups below that match the files you touch.
2. Make the smallest change that solves the task, following the code around it.
3. Run the commands above for the affected packages and capture proof when the change is visible.
4. Add one ADR entry in `decisions/`.
