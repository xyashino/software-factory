# Open questions

Each question has a recommended default. The docs already assume the default; changing it means a
`decisions/` entry and an update to the affected documents.

| #   | Question                                                                              | Default                                                                                | Why / consequence                                                                                                                                                                                                                           |
| :-- | :------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Q1  | Do we need a highly available Factory?                                                | **No** in v2.0                                                                         | One Factory; Cells ride out outages shorter than the self-fence window (PROTOCOL §11). HA later = Postgres + leader election; the append-only model allows it.                                                                              |
| Q2  | SQLite or Postgres now?                                                               | **SQLite**                                                                             | One writer process; simplest ops; async ports keep Postgres a drop-in (STORAGE §1).                                                                                                                                                         |
| Q3  | Multiple projects from day one?                                                       | **Schema yes, operate one**                                                            | `projectId` is in ids, events and tables, so adding a second repo is configuration, not migration.                                                                                                                                          |
| Q4  | When is a dependency satisfied?                                                       | **PR opened (`delivered`)**, per-project switch to `merged`                            | v1 parity. `merged` is safer for stacked changes but slower; under `merged`, a PR closed unmerged makes the dependency broken (CORE §8).                                                                                                    |
| Q5  | Where are prompts rendered?                                                           | **Factory**                                                                            | Deterministic, stored as a blob (audit), Cells need no definitions. Cost: the Factory holds templates, including runtime prompts.                                                                                                           |
| Q6  | Can a running Work order move to a newer Line?                                        | **No** in v2.0                                                                         | Pinned snapshot. Workaround: cancel and add a todo under a new name (`TodoId`s are never reused). Later: explicit `line_upgraded` with a Station mapping.                                                                                   |
| Q7  | Should Station outputs also live in git (side ref) so git-only recovery is complete?  | **No**                                                                                 | Litestream/export cover R1; adds git noise. Revisit if M8 recovery proves too lossy.                                                                                                                                                        |
| Q8  | Can a target repo override Operator profiles or Lines (e.g. `.factory/` in the repo)? | **Not in v2.0**                                                                        | Factory-shipped definitions only. Later: per-project definitions directory, still snapshotted at Work order creation.                                                                                                                       |
| Q9  | Slots per Cell?                                                                       | **2**                                                                                  | Each slot = its own worktree and pane. Inspections are CPU-heavy; tune per Cell in `config.toml`.                                                                                                                                           |
| Q10 | Question hold before forcing a Handover?                                              | **30 min**                                                                             | Balances a quick answer against a Cell sitting idle. Per-Line setting later.                                                                                                                                                                |
| Q11 | Network between Cells and the Factory?                                                | **Tailscale/WireGuard**                                                                | No TLS code in v2. The Factory binds `127.0.0.1` by default; set `FACTORY_BIND` to the private interface. A TLS reverse proxy is the alternative.                                                                                           |
| Q12 | Squash at delivery or keep checkpoint history?                                        | **Squash**                                                                             | v1 parity, clean PRs. The pre-squash checkpoints are gone from the remote after delivery; their shas stay in the Traveler as history only. Reopened Work orders build on the delivery commit.                                               |
| Q13 | Does a `restart` after `lost` reuse the WIP?                                          | **No, clean base**                                                                     | A lost Cycle's work is of unknown state. The Supervisor can still inspect `factory-wip/<todoId>/<cycleId>`. A Cell that leaves on purpose hands over instead, and that _does_ continue from the WIP.                                        |
| Q14 | Is the Line lead (v1's on-call operator) part of v2.0?                                | **No, M10**                                                                            | It is the largest source of complexity in v1's engine. Andons go to the Supervisor until then.                                                                                                                                              |
| Q15 | Token rotation and expiry?                                                            | **Join tokens may expire; Cell credentials and supervisor tokens: manual revoke only** | Small, trusted fleet. Expiring credentials later without protocol changes.                                                                                                                                                                  |
| Q16 | Lease TTL and self-fence window?                                                      | **60 s / 45 s**                                                                        | Short windows give fast takeover after a crash but cost every in-flight Cycle when the Factory is down longer than 45 s. Raise both together (e.g. 10 min / 9 min) if Factory restarts are slow; takeover after a crash then takes as long. |
| Q17 | Where do large log blobs live?                                                        | **In SQLite**                                                                          | One file to back up. Logs dominate size and are kept forever. Later: a file or object store behind the `BlobStore` port, and an age-based sweep for logs only.                                                                              |
| Q18 | Who can an Operator ask?                                                              | **The Supervisor only**                                                                | v2.0 has no Line lead. `factory-operator ask` gets a `to` option again in M10.                                                                                                                                                              |
